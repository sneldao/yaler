# Market and strategy

## Executive conclusion

The broad thesis of an agent marketplace is already crowded. Existing products and protocols cover agent discovery, agent interoperability, autonomous procurement, agent payments, identity, and generic agent-to-human work.

Yaler should not compete as another agent directory or general-purpose agent economy. Its wedge is narrower:

> **Trusted autonomous coordination of fragmented, local, real-world business capacity.**

The initial market is London independent hospitality operations, starting with urgent commercial kitchen uptime and adjacent low-risk services.

## Adjacent landscape

### Agent interoperability

[Google A2A](https://developers.googleblog.com/en/a2a-a-new-era-of-agent-interoperability/) provides agent cards, task lifecycles, long-running task updates, and a protocol for a client agent to collaborate with a remote agent. Yaler should use compatible concepts where helpful, but A2A is infrastructure rather than Yaler's product wedge.

### Agent registries and marketplaces

[Google Cloud Agent Registry](https://docs.cloud.google.com/agent-registry/overview) catalogs and governs agents, MCP servers, skills, and endpoints. [Fetch Agentverse](https://www.fetch.ai/agentverse) focuses on hosting, discoverability, marketing, and measurement. [Salesforce AgentExchange](https://agentexchange.salesforce.com/) is an enterprise marketplace for trusted agents, apps, and skills.

These products make agents discoverable. Yaler must make a mission finishable.

### Agent societies and agent commerce

[Virtuals Protocol](https://www.virtuals.io/) describes a society of productive agents that can create services and engage in on-chain commerce. [Google AP2](https://cloud.google.com/blog/products/ai-machine-learning/announcing-agents-to-payments-ap2-protocol) provides signed mandates and a trust foundation for agent-led transactions. [Skyfire](https://skyfire.xyz/) focuses on verified agent identity and payment credentials. [Nevermined](https://nevermined.ai/) focuses on agent spending, metering, monetization, and settlement.

These layers make agents economically capable. They do not by themselves solve local job scoping, provider reliability, milestone coordination, or completion evidence.

### Autonomous procurement

[Pactum](https://pactum.com/) and [Zycus Merlin ANA](https://www.zycus.com/solution/merlin-ana) demonstrate that autonomous supplier negotiation is already a serious enterprise category. Their focus is enterprise procurement, scale, and savings. Yaler should not present itself as a smaller Pactum.

Yaler's distinction is fragmented local providers, urgent operational work, lightweight onboarding, and outcome evidence rather than enterprise spend optimization.

### Agent-to-human work

[RentAHuman](https://rentahuman.ai/) positions itself as a marketplace where agents can hire people for physical-world tasks. It is the closest conceptual neighbor. Yaler should differentiate through a specific business vertical, provider capability records, two-sided mandates, local reliability data, and proof receipts—not generic task labor.

## Strategic whitespace

The whitespace is the intersection of:

- Local business demand
- Fragmented provider supply
- Ambiguous real-world jobs
- Low-bandwidth communication
- Agent-to-agent coordination
- Human safety and escalation
- Evidence-backed completion

The key insight is:

> The first valuable agent economy may not be agents buying software from one another. It may be agents making fragmented offline capacity legible, negotiable, and accountable.

## Peter Thiel lens

### Small market

Begin with independent cafés, restaurants, and takeaways in one reachable London area. Narrow the first mission class to urgent, low-risk operational services.

Do not start with all local services, all small businesses, or all agents.

### Secret

The difficult problem is not model intelligence or agent discovery. It is trustworthy coordination when the buyer and supplier lack a common operating system, the job description is messy, and the outcome is partly physical.

### Creative monopoly

The defensible asset is the local outcome graph:

- Provider capability
- Response speed
- Quote accuracy
- Arrival reliability
- Completion evidence
- Rework rate
- Mission-specific performance

This graph becomes more valuable with every completed mission and is difficult for a generic platform to reproduce without local operations.

### Distribution built into the product

Every completed mission should produce:

- A redacted proof receipt
- A portable supplier agent card
- A request-similar-mission link
- A provider referral path
- A buyer referral path

The product should create its own distribution through useful evidence, not depend only on advertising or social posts.

## Paul Graham lens

### Make something people want

The first user does not want an agent marketplace. They want a broken fridge, urgent cleaning job, or equipment problem handled quickly.

The product should sell the outcome, not the platform.

### Do things that do not scale

For the first ten missions:

- Personally recruit a few demand-side businesses.
- Personally curate a small supplier network.
- Manually verify supplier details.
- Manually resolve exceptions.
- Interview both sides after each mission.
- Automate only the repetitive coordination.

A human concierge layer is a learning advantage until the workflow is understood.

### Solve the cold start

Start demand-first. Yaler can initially maintain a curated supply pool rather than waiting for an open marketplace to reach liquidity. Supplier self-registration comes later, after the demand workflow repeats.

### Growth should follow usage

Do not build a large platform before proving that a buyer will delegate a second mission. The critical validation signal is repeat demand, followed by provider willingness to accept work through an agent-mediated process.

## Strategic risks

- A generic marketplace can be copied quickly.
- Local provider quality and safety are difficult to verify.
- A two-sided network can stall without concentrated demand.
- Autonomous negotiation can damage supplier trust if it optimizes only for price.
- Regulated work creates liability and must be escalated.
- Public proof can expose business-sensitive information.

Yaler's response is narrow geography, narrow workflow, explicit mandates, evidence requirements, provider dignity, and human escalation.
